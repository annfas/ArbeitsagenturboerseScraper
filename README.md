# Arbeitsagentur Job Scraper

Ein Python-Script zum automatisierten Abrufen von Stellenangeboten von der Jobbörse der Arbeitsagentur.

## Funktionen
- Abruf von Stellenangeboten über die offizielle API
- Filterung nach Ort, Umkreis und Angebotsart
- Pagination über mehrere Seiten
- Strukturierte Ausgabe der Ergebnisse

## Technologien
- Python 3
- requests Library
- REST API Integration

## Verwendung
```python
python jobscraper.py
```
